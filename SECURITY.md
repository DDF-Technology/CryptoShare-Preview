# Security notice

CryptoShare Full 1.0.0-rc.1 and Demo 1.0.0-demo.1 are pre-release software without an independent
cryptographic security audit. Do not use them for production, irreplaceable, regulated or otherwise
critical data.

Decryption requires every generated all-of-N key share. Depending on the selected workflow, the
external dictionary and correct RSA material are also required. Losing or corrupting one required
item can make encrypted data permanently unrecoverable.

Report potential vulnerabilities privately through https://www.ddf.technology/ rather than a
public issue.
